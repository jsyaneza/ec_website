# Academic Portfolio - Juan Sebastián Yáñez Albarracín

Academic portfolio website for **Juan Sebastián Yáñez Albarracín**, researcher in regional econometrics, spatial development, and quantitative economic geography at Nagoya University.

## 🌐 Access the Website

Your web page is deployed on GitHub Pages:
👉 **https://jsyaneza.github.io/ec_website/**

## 🏗️ Site Architecture & Structure

The repository is designed as a clean, self-contained multi-tab academic portfolio featuring a fixed dark sidebar layout and a responsive main content area:

- **Left Sidebar (`320px` width):** Features a circular profile photo (`photo.jpg`), personal and academic identification details, contact information, and a dedicated procedural background animation layer (`sidebar-animation.js`).
- **Main Content Area:** Organised into three core interactive tabs:
  1. **Research Interests:** Outlines academic motivation, background experience in the food sector, and core research lines focusing on regional econometrics and transport infrastructure.
  2. **Curriculum Vitae:** Details academic background (including Nagoya University Master's program and prior degrees) and professional experience as CFO and Business Development Manager at UNOSEIS18.
  3. **Master's Thesis Project:** Features an interactive timeline broken down into academic milestones (M1 and M2 stages) evaluating road infrastructure improvements in Colombia using Difference-in-Differences and Synthetic Control methodologies. Includes direct access to the [Stage 1 Streamlit Dashboard](https://colombia-road-infrastructure-data-stage-1-unoa3z92n8mhbwwejis8.streamlit.app/).

## 🎨 Interactive Visual Features

- **Procedural Sidebar Animation (`sidebar-animation.js`):** A custom HTML5 Canvas script running behind the sidebar content that procedurally generates a video-game-like dual-lane road with a three-car caravan and an intermittent lateral traffic light mechanism featuring timed stops.
- **Interactive Thesis Timeline:** Built with GSAP and ScrollTrigger, allowing users to click milestone nodes to expand detailed cards containing stage results, notes, and direct web links.

## 🛠️ Technologies

- HTML5 & CSS3 (Custom styling and responsive grid/flexbox layouts)
- Vanilla JavaScript (Canvas API & procedural generation logic)
- GSAP & ScrollTrigger CDN (Interactive timeline transitions)
